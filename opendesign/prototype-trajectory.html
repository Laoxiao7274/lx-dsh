调研六规则 → v4 落点

  1. 步骤树是主角 → 事件树 + 肘形连接线;瀑布降级为 36px minimap(保留刷选/缩放交互)
  2. 类型 = 小图标 → 18px 描边圆角方(人=输入 / 星=回应 / 扳手=动作 / 虚线横杠=系统),零彩色底行
  3. 时延上色 → 240ms 灰、34.1s 琥珀、>40s 红;类型色只出现在 18px 图标描边
  4. 时长贴名 → pwsh vitest run… 80ms,右侧只留状态图标;轮次摘要收进 chip 2 steps · 45.2s
  5. 检查器 = Langfuse 式 → 图标+名称 → chip 行(状态/耗时/请求/调用方)→ 下划线 tabs → 输入/输出描边卡
  6. 近乎单色 → 白/近黑底、灰字、accent 只给选中与链接;等宽只给名称与 JSON

证据来源

  1. Langfuse Trace 视图:列表+树+右侧详情,慢时延橙红 / 正常灰langfuse.com/docs/tracing
  2. LangSmith Trace:默认树、时延贴名、右侧 Input/Output 描边卡;瀑布只是按钮langchain.com/langsmith 产品页
  3. GitHub Copilot coding agent:PR 内日志流安静、命令灰块github.blog 2025-05
  4. Claude Code web / Codex cloud:transcript 流,小图标 + 等宽命令行,无彩色行anthropic.com/news、openai.com
