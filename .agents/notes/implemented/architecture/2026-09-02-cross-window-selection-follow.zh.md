# Agent Note：同源窗口跟随同一份持久化会话选择

Status: implemented

[English](2026-09-02-cross-window-selection-follow.md) | 中文

## 问题

一个后端可以正确地服务任意数量的客户端——每个浏览器页面各自打开 `remote.mux` WebSocket、各自的 `session/control` 与 `session/follow` 流，Host 把每条实时事件扇出给每个跟随者（已对运行中的生产后端验证：两个裸 WebSocket 客户端与两个真实浏览器窗口各自收到逐条一致的事件序列，含 `assistant/chunk` 思考增量与工具活动）。但同一浏览器的两个窗口在「显示什么」上会分叉：`dsh.sessions.current` 按源持久化在 localStorage、只在启动时读取，两个窗口各自导航之后就停在各自会话上，用户读作「消息只同步到一个客户端」。多实例部署（两个 LX-DSH 壳各自拉起私有回环后端）是另一个架构缺口，不在本笔记范围内解决。

## 决策

- **跨窗口写入经由用户点击路径重定向每个同源窗口。** `ClientSessions` 监听 `dsh.sessions.current` 键上的 `storage` 事件（`rootCtx.effect` 持有，销毁即注销）。一个与本客户端当前值不同的已验证外来选择成为 pending follow；应用时调用与侧栏点击完全相同的 `open()` / `openSubagent()` / `clear()`，持久化单元、staged scope、事件窗口与 UI 一起移动。
- **未知目标保持 pending，绝不破坏。** `manager.select` 对本窗口尚未列出的 id 会抛错，catalog 子会话还需要其父目录。pending follow 在每次列表发布时重试：普通会话在其行列入后应用，带地址的子会话在本窗口的父目录携带匹配的健康条目后应用（子行只沿当前地址路由投影，所以目录快照——而非 `byId`——是其可寻址来源）。新会话竞态因此在一个列表更新内收敛，而不是抛错或清空持久化单元。
- **localStorage 仍是经过验证的持久化边界。** `parsePersistedSelection` 只接受 store 会写出的确切形状（`{}`、`{sessionId}`、`{sessionId, subagentAddress}`，地址的 mode 受约束）；其余一律忽略而非信任。相等的选择（回声）是 no-op，所以窗口收敛不产生写循环——应用外来值会重新发布相同 JSON，不再触发进一步的 storage 事件。
- **不同浏览器 profile 保持独立视图。** 跟随只搭 storage 事件的便车，而它只跨越同一 profile 的同源窗口。两个不同浏览器连到同一后端仍各自选择（两者打开同一会话时实时流照常同步——该路径本来就正确）。

## 考虑过的替代方案

**服务端全局「当前会话」共享给所有客户端。** 一个全局选择能保证跨浏览器的相同视图。否决：选择是视图状态而非会话状态；两个真实用户（或一个刻意双视图的用户）会争抢同一个指针，且客户端选择还驱动侧栏高亮、冻结 scope 舞台等本地 UI。

**让跟随走 manager 的 restore 语义。** `SessionManager` 已接受启动时的恢复选择并遮蔽未知 id。否决：遮蔽间隙的投影会把持久化单元清成 `{}`，而该清空会广播给其他所有窗口——瞬态竞态会拽走原窗口的视图。pending-follow 设计直到目标在本窗口可寻址才写入。

**在 `client/store` 做通用跨标签同步层。** 把持久化通用化成 `storage` 事件镜像会同步每个持久化 store（面板宽度、草稿）。暂缓：今天只有会话选择产生「两个窗口应显示同一对话」的预期；将来可以在 `attachPersistence` 上加通用层而不改变本笔记的契约。

## 后果

同一 LX-DSH 壳的所有窗口（主窗口、web view 窗口、同 profile 浏览器标签）现在 stage 同一会话并实时流式；在一个窗口切换会话，其他窗口在一个列表发布内跟随。遮蔽间隙的启动清空在罕见竞态下（某窗口的列表拉取恰逢另一窗口创建会话）仍可能广播 `{}`；收敛是自愈的——行到达后重新发布选择，跟随的窗口重新打开它。跟随一个未注册 cwd 的 blank 会话、其草稿视图重写持久化选择时，最终单元为空——那是 blank-draft 流程自身的行为，本笔记未改变。真实行为已对真实后端用两个浏览器窗口端到端验证：任一窗口的写入都重定向了另一个窗口，其 follow 流为目标会话打开快照，视图完成切换。
