# Agent Note: 外网访问设置行与远程后端连接书签

Status: implemented

[English](2026-09-01-remote-access-row-and-connection-bookmarks.md) | 中文

## Problem

客户端无关的 API 面（Bearer 鉴权、mux 查询令牌、`/api/$schema`）已让运行中的宿主可被其它机器访问，但用户无从*找到*该输入什么：连接要素（带令牌的 URL、局域网地址、绑定姿态）只出现在启动控制台行里，另一台机器上的用户也没有被引导的方式去*使用*它们。同时 web UI 唯一的"添加"路径是本地目录——连接第二个后端（拆分后自然的第一个客户端）需要手拼 URL。

## Decision

- **`settings.connectionInfo()` 加入 settings Remote 命名空间。** 返回带令牌的根 URL（与打印的启动 URL 同等敏感度）、web-app 运行时采样的局域网 IPv4 字面量、以及 webserver 是否仅回环。通过 `ctx.get` 读 `webRuntime`（可选服务；无此服务的组合得到空局域网列表），直接读 `webServer.host`/`port`。
- **通用设置区新增「外网访问」行。** `role="switch"` 的揭示开关控制信息区：地址（含令牌）、各局域网地址、以及姿态提示——回环提示点名 `--host 0.0.0.0` 是开启步骤，已暴露提示说把地址交给要连接的客户端。每个要素行带复制按钮，经共享 `writeClipboard` 助手给出短暂的"已复制"反馈。该行默认收起、不持久化状态：开关只管显示，绑定是启动决策而非运行时决策。
- **远程后端通过浏览器本地书签连接，不进 Workspace 模型。** `remote-connections.ts` 把用户输入解析并归一为精确的 `scheme://host[:port]` origin（接受裸 `ip:port`；拒绝凭据、路径、查询、fragment），并把令牌拼在查询串上组装打开 URL。`createRemoteConnectionsStore`（持久化 `dsh.workspace.remote.v1`）持有书签列表；`apply` 里建一个句柄传给 picker 注册。picker 的添加菜单新增**连接远程后端…**，打开表单弹窗（名称、地址、可选令牌、可移除的已存书签列表）；保存后在新标签打开远程后端自己的 web UI——该后端服务完整前端，因此不存在会话混流。已存书签以地球图标列在菜单里，选中即打开。
- **自动展开折叠现在要求确实存在 flow 占用者。** 连接入口常驻后，`addEntries.length === 1` 不再蕴含"目录添加是唯一动作"：在无 flow 的组合里它意味着自动展开 effect 与 flow 撤回 effect 以无限 setState 循环互搏（该渲染循环最初伪装成测试挂死）。守卫加入 `flowAvailable`，无 flow 且无列表的 picker 现在显示单入口菜单（远程连接）而非不显示弹出菜单。

## Alternatives considered

**远程后端作为 Workspace 记录（`kind: 'remote'`）。** 在 Workspace 注册表里建模远程后端可以让它免费出现在所有工作区表面。暂被否：Workspace 模型以路径为锚（realpath、会话头索引、cwd 锚定）——远程记录需要触及实体、注册表、持久化与引导的模型级变体，而用户需求（记一个地址、打开它）不需要任何这些机器。书签留在浏览器本地出于同一论证：后端 A 不能拥有指向后端 B 的连接记录。

**设置行里的运行时绑定开关。** 开关可以按需把 webserver 重绑到 `0.0.0.0`。被否：绑定是带安全姿态（可信主机、防火墙）的启动决策；运行时翻它反正要重启周期，只管显示的开关加上点出开启旗标让这一行保持诚实。

**书签经当前页面的 API 内联取数。** 通过 CORS 内联取远程数据会把远程会话集成进本地 UI。被否：多后端会话混流是被决策推迟的多用户/多账号方向；打开远程后端自己的 UI 今天就以零协议工作量给出了可用客户端。

## Consequences

一对用户现在可以端到端连通：服务机打开 设置 → 通用 → 外网访问，复制地址；客户机的 picker 发起连接，保存书签，带令牌打开远程 UI。书签只在该浏览器存活——重装或换浏览器需重录地址（令牌可从设置行取）。`connectionInfo` 方法进入契约面（schema 端点会列出它），未来客户端仅凭 `/api/$schema` 就能渲染同一行。自动展开守卫的变化改变一个可观察行为：无目录选择器且无工作区的组合现在显示单入口菜单而非无弹出菜单——远程连接是真实选择，弹出菜单就声明一个真实选择。
